# Retail Sales Forecasting

## Project Overview
This project focuses on time series forecasting using the Store Item Demand Forecasting dataset.

The daily sales data is aggregated into monthly total sales to analyse sales trends and forecast future sales.

## Dataset
- Dataset: Store Item Demand Forecasting Challenge
- Source: Kaggle
- Original records: 913,000
- Time period: January 2013 – December 2017
- Forecasting frequency: Monthly

## Models Implemented
1. Auto Regression
2. ARIMA
3. SARIMA

## Evaluation Metrics
- Root Mean Squared Error (RMSE)
- Mean Absolute Percentage Error (MAPE)
